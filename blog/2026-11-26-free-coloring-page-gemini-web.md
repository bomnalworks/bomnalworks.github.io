# 컬러링북 그림을 0원으로 - API 대신 Gemini 웹 구독으로 만들어 본 기록

아마존 KDP에 AI 컬러링북을 한 권 내 보는 중입니다. 시니어용 큰 그림 컬러링북이고, 그림은 30장입니다.

첫 권의 그림은 **유료 API**로 만들었습니다. 그림 30장과 표지를 합쳐 약 2달러가 들었습니다. 큰돈은 아니지만, 이미 매달 내는 AI 구독이 있는데 그림값을 따로 낸 셈입니다. 그래서 다음 권은 **구독 안에서 0원으로** 만들 수 있는지 시험했습니다.

## 결론부터

| 방법 | 비용 | 결과 |
|---|---|---|
| Gemini API (무료 키) | 0원 | **안 됨** - 무료 등급은 이미지 생성 쿼터가 0 |
| 유료 이미지 API (첫 권) | 30장 + 표지 약 2달러 | 품질 좋음, 장당 약 20초 |
| Claude에게 직접 그리게 하기 (SVG) | 0원 (구독) | 사과 같은 단순한 사물만 됨, 동물은 안 됨 |
| **Gemini 웹 (Pro 구독)** | **0원 (구독)** | **됨** - 장당 1분 안팎, 해상도도 충분 |

다음 권은 **Gemini 웹**으로 만들기로 했습니다.

## 1. Gemini API 무료 키는 처음부터 안 됩니다

첫 권을 만들 때 Gemini API부터 불렀는데 바로 오류(429, 쿼터 초과)가 났습니다. 처음엔 "하루 무료량을 다 썼나" 했는데 아니었습니다. **무료 등급 API 키는 이미지 모델 쿼터가 처음부터 0**입니다. 내일이 와도 풀리지 않습니다.

Gemini Pro를 구독하고 있어도 마찬가지입니다. **구독과 API는 요금이 따로**라서, 구독이 있다고 API 쿼터가 생기지는 않습니다. 결국 첫 권은 다른 회사의 유료 이미지 API로 넘어가서 만들었습니다.

## 2. Claude에게 직접 그리게 하면?

Claude는 그림 파일을 만들지 못합니다. 대신 **SVG**는 쓸 수 있습니다. SVG는 선과 도형을 글자로 적은 그림 파일이라, 글을 쓰는 AI도 만들 수 있습니다. 컬러링북은 흰 바탕에 검은 선이라 해 볼 만하다고 생각했습니다.

같은 주제로 두 장을 그려 달라고 했습니다.

![Claude가 SVG로 그린 사과](/images/2026-11-26/svg-apple.jpg)

사과는 쓸 만합니다. 선 굵기가 일정하고, 색칠할 칸이 모두 닫혀 있습니다.

![Claude가 SVG로 그린 쿠션 위 고양이](/images/2026-11-26/svg-cat.jpg)

고양이는 못 씁니다. 귀가 겹쳐 엉켰고, 꼬리는 모양이 무너졌고, 그림이 페이지 아래로 쏠렸습니다. 같은 주제를 이미지 AI로 만든 첫 권의 그림과 비교하면 차이가 확연합니다.

![이미지 AI로 만든 첫 권의 고양이 그림](/images/2026-11-26/openai-cat.jpg)

**사과·컵케이크·찻주전자 같은 단순한 사물만 된다**고 보면 됩니다. 동물이나 장면이 들어가는 책이라면 이 방법만으로는 한 권을 채우기 어렵습니다.

## 3. Gemini 웹에서 만들어 받기

[gemini.google.com](https://gemini.google.com/)에 Pro 계정으로 들어가서 첫 권에 쓴 프롬프트를 그대로 붙여 넣었습니다. 맨 앞에 "그림을 만들어 달라, 세로 2:3 비율"만 덧붙였습니다.

> Generate an image, vertical portrait 2:3 aspect ratio. Black and white coloring book page in a bold and easy, large print style for seniors. Subject: a big round apple with one leaf on the stem. Extra-thick, uniform, smooth black outlines (as thick as a marker line), very large simple shapes with only a few details, every area big enough to color easily with a crayon, all shapes fully closed. Pure white background. No frame, no border, no rectangle around the picture, no shading, no gray tones, no hatching, no texture, no text, no letters, no numbers, no people, no hands. The subject is centered and fills about 80 percent of the page.

약 20초 만에 그림이 나왔습니다.

![Gemini 웹에서 받은 사과 그림](/images/2026-11-26/gemini-web-apple.jpg)

받은 파일은 이랬습니다.

- 이름: `Gemini_Generated_Image_(임의 문자).png`
- 크기: **1696 x 2528** 픽셀, 세로 비율. 첫 권에 쓴 유료 API 그림(1024 x 1536)보다 큽니다
- 눈에 보이는 워터마크: 없음
- 첫 권 때 만든 자동 검수(액자 그림 여부, 회색 음영, 선 두께)도 통과

### 함정 1 - 다운로드 버튼이 두 번입니다

그림 위의 다운로드 아이콘을 눌렀더니 파일이 바로 받아지지 않고 **이미지 보기 화면**이 열렸습니다. 그 화면 **오른쪽 위의 다운로드 버튼**을 한 번 더 눌러야 받아졌습니다. 30장을 받을 생각이면 처음부터 알고 있는 게 좋습니다.

### 함정 2 - 선 일부가 번져 있습니다

크게 보면 몰랐는데, 확대해 보니 윤곽선 몇 군데가 붓으로 문지른 것처럼 뿌옇습니다.

![오른쪽 윤곽선을 확대한 모습. 선 가장자리가 번져 있습니다](/images/2026-11-26/gemini-web-edge.jpg)

인쇄하면 선 가장자리가 살짝 거칠게 나올 수 있습니다. 첫 권 때 만든 정리 스크립트가 회색을 흰색이나 검은색으로 밀어 주기 때문에 대부분은 정리되지만, 받을 때마다 확대해서 한 번씩 보기로 했습니다.

## 4. 30장을 받는 일은 Claude에게 맡깁니다

장당 1분이면 30장에 30~40분입니다. 붙여 넣고, 기다리고, 두 번 눌러 받고, 파일 이름을 바꿔 폴더에 넣는 일의 반복입니다.

이번에는 이 반복을 **Claude in Chrome**(Claude가 내 크롬 브라우저를 대신 조작하는 확장 프로그램)에 시켜 봤습니다. 사과 한 장으로 "프롬프트 넣기 → 생성 기다리기 → 다운로드 → 작업 폴더로 옮기기"까지 끝까지 됐습니다.

두 가지는 미리 적어 둡니다.

- 자판으로 한 글자씩 치게 했더니, 이전에 다른 작업에서 **입력창 맨 앞에 깨진 글자가 붙은 적**이 있습니다. 이번에는 문장을 통째로 붙여 넣게 해서 피했습니다.
- 구글 서비스를 프로그램으로 대량 조작하는 건 약관상 애매한 영역입니다. 메일·유튜브와 묶인 계정이라 **사람이 하는 속도로, 필요한 장수만** 하기로 했습니다.

## 5. 아직 확인하지 않은 것

- **무료 Gemini 계정**에서도 같은 품질로 되는지, 하루 몇 장까지인지는 시험하지 않았습니다. 저는 Pro 구독으로만 해 봤습니다.
- Pro 구독에도 하루 생성 한도가 있습니다. 30장은 들어갈 것으로 보지만, 다음 권을 실제로 만들면서 확인하겠습니다.
- 눈에 보이는 워터마크는 없었지만 **보이지 않는 표식**(구글 SynthID)은 들어 있습니다. 어차피 KDP에 올릴 때는 AI로 만든 그림이라고 신고합니다.

첫 권은 이미 만든 그림으로 KDP 등록을 진행하고, 다음 권은 이 방법으로 30장을 처음부터 끝까지 만들어 보겠습니다. 실제로 걸린 시간과 탈락한 그림 수는 그때 다시 적겠습니다.
