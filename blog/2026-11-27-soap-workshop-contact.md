# 홈페이지 월세 탈출 3편 - 문의 버튼 달기, 구글 폼으로 0원 문의 창구 만들기

[2편](/blog/2026-11-24-soap-workshop-edit)에서 홈페이지의 자리 표시를 고쳤습니다. 마지막까지 남은 건 **연락 버튼**이었습니다. 카카오톡 문의 버튼 6개는 아직 아무 데도 연결되지 않았고, 인스타그램 링크와 지도 자리도 비어 있었습니다.

홈페이지는 손님이 연락할 수 있어야 쓸모가 있습니다. 이번 편은 그 버튼을 채우는 이야기입니다. 이번에도 코딩은 하지 않았고, 클로드 채팅과 구글 폼, GitHub 웹 화면만 썼습니다.

결과물: [bomnal-lab.github.io](https://bomnal-lab.github.io/) (맨 아래 "문의하기" 버튼)

## 결론부터

| 단계 | 걸린 시간 |
|---|---|
| 클로드에게 연락 방법 제안받기 | 약 4분 |
| 구글 폼 만들기 (질문 5개) | 약 8분 |
| 게시하고 주소를 클로드에게 건네기 | 약 3분 |
| 고친 파일 올리고 확인 | 약 5분 |
| **합계** | **약 20분**, 비용 0원 |

사업자 정보 없이 바로 시작하려면 **구글 폼**이 가장 무난합니다. 실제로 가게를 운영 중이라면 카카오톡 채널도 좋습니다.

## 1. 무엇을 연결할지부터 물어봅니다

1편 때처럼 "어떻게 하면 좋을지 제안해 달라"로 시작했습니다. 1편을 만든 그 대화에서 이어서 보냈습니다.

> 이제 카카오톡 문의 버튼이랑 인스타, 지도가 남았어. 손님이 연락할 방법을 어떻게 연결하면 좋을지 2~3가지 제안해줘. 돈 안 드는 걸로

![클로드가 세 가지 방법의 좋은 점과 아쉬운 점을 정리하고 추천 조합까지 냈습니다](/images/2026-11-27/chat-contact-options.jpg)

클로드는 세 가지를 장단점과 함께 정리했습니다.

| 방법 | 좋은 점 | 아쉬운 점 |
|---|---|---|
| 카카오톡 채널 1:1 채팅 | 손님 대부분이 카톡을 써서 문의가 가장 쉽다 | 개설할 때 전화번호 인증, 손님이 먼저 말을 걸어야 한다 |
| 구글 폼 문의서 | 구글 계정만 있으면 바로, 날짜·인원 같은 칸을 정해 둘 수 있다 | 채팅처럼 바로 주고받지는 못한다 |
| 인스타그램 DM 바로가기 | 사진을 보고 온 손님이 바로 묻는다 | 계정을 꾸준히 관리해야 한다 |

인스타그램 링크를 `https://ig.me/m/아이디` 형태로 걸면 프로필이 아니라 **DM 창이 바로 열린다**는 것도 이번에 알았습니다.

예시가 가상 공방이라 클로드는 **구글 폼을 중심에 두고 문의 버튼을 모두 폼에 연결하자**고 했습니다. 주소가 없으니 지도 칸과 지도 버튼은 지우자고 먼저 짚었습니다. 2편에서 제가 마지막에야 찾은 "지도 영역" 상자입니다.

"돈 안 드는 걸로" 한마디도 중요합니다. 이 말이 없으면 월 사용료가 있는 상담 도구를 추천받을 수 있습니다.

## 2. 폼 질문은 5개 안쪽으로

"구글 폼에 넣을 질문 목록 먼저 만들어줘"라고 했더니, 문의 종류마다 질문이 갈라지는 **질문 23개짜리** 폼이 나왔습니다. 꼼꼼하긴 한데, 옮겨 적다 지치고 손님도 쓰다 지칩니다.

### 함정 1 - 처음 받은 답은 길 수 있습니다

이렇게 다시 말했습니다.

> 너무 길어. 섹션 나누기 없이 5개 안쪽으로 줄여줘. 파일 업로드는 빼고, 개인정보 동의는 넣어줘.

![질문 5개로 줄인 목록](/images/2026-11-27/chat-form-short.jpg)

**숫자를 정해서** "5개 안쪽"이라고 하고, 빼고 싶은 것과 꼭 넣을 것을 같이 말하면 한 번에 끝납니다. 줄인 질문은 이렇습니다.

1. 이름 (단답형)
2. 연락처 (단답형) - "휴대폰 번호나 이메일 중 편한 것을 적어주세요."
3. 문의 종류 (객관식) - 어린이 클래스 / 기업 체험 클래스 / 맞춤 선물 주문제작 / 기타
4. 문의 내용 (장문형) - "희망 날짜, 인원(또는 수량), 요청사항을 적어주세요."
5. 개인정보 수집·이용 동의 (체크박스) - "동의합니다"

다섯 개 모두 필수로 했습니다.

클로드가 처음 목록에서 짚어 준 두 가지는 기억해 둘 만합니다.

- **파일 업로드 질문을 넣으면 손님이 구글 로그인을 해야** 폼을 쓸 수 있습니다. 문의 문턱이 높아집니다.
- 이름과 연락처를 받으니 **개인정보 수집·이용 동의**를 넣습니다. 실제로 운영한다면 보관 기간 같은 내용을 상황에 맞게 다듬으세요.

## 3. 구글 폼 만들기

1. [forms.google.com](https://forms.google.com/)에 들어가 **빈 양식**을 누릅니다.
2. 맨 위에 제목("봄날비누공방 문의하기")과 설명을 넣습니다.
3. 질문을 하나씩 넣습니다. 질문 제목을 쓰면 유형이 저절로 바뀌기도 합니다. "이름"은 단답형, "문의 내용"은 장문형으로 알아서 바뀌었습니다.
4. 객관식 선택지는 첫 칸에 쓰고 **Enter**를 누르면 다음 칸이 생깁니다.
5. 질문마다 오른쪽 아래 **필수** 스위치를 켭니다.

### 함정 2 - 오른쪽 막대의 `Tт`는 질문이 아닙니다

![질문처럼 보이지만 답 칸이 없는 '제목 및 설명' 블록](/images/2026-11-27/form-textblock-trap.jpg)

연락처 질문에 설명을 붙이려다 오른쪽 막대의 **`Tт`(제목 및 설명)**를 눌렀습니다. 겉보기엔 "연락처 / 휴대폰 번호나 이메일 중…"으로 그럴듯하지만, **답을 쓰는 칸도 필수 스위치도 없습니다.** 손님은 읽기만 하고 답할 수 없습니다.

오른쪽 막대 아이콘은 위에서부터 이렇습니다.

| 아이콘 | 하는 일 |
|---|---|
| ⊕ | 질문 추가 |
| 화살표가 들어간 문서 | 다른 폼에서 질문 가져오기 |
| Tт | 제목·설명 (안내 글, 답 칸 없음) |
| 그림 / 재생 버튼 | 사진 / 동영상 넣기 |
| 두 칸짜리 상자 | 섹션 나누기 |

**질문에 설명을 붙이려면 그 질문 카드 오른쪽 아래 ⋮ → "설명"**을 누릅니다. 질문 제목 아래에 설명 칸이 생깁니다.

![질문 카드의 ⋮ 메뉴에 '설명'이 있습니다](/images/2026-11-27/form-description-menu.jpg)

설명을 넣으면 카드가 길어지면서 필수 스위치가 아래로 내려갑니다. 다 만든 뒤에는 질문 제목 옆에 **빨간 `*`**가 붙었는지로 필수를 확인하세요.

![다섯 질문 모두 빨간 * 가 붙었습니다](/images/2026-11-27/form-done.jpg)

화면 왼쪽 위의 파일 이름은 폼 제목과 따로입니다. 그대로 두면 "제목 없는 설문지"로 저장되니, 그 글자를 눌러 폼 이름으로 바꿔 두면 나중에 구글 드라이브에서 찾기 쉽습니다.

## 4. 게시하고 주소 복사하기

### 함정 3 - "게시"를 눌러야 손님이 열 수 있습니다

지금 구글 폼은 만들기만 해서는 손님에게 열리지 않습니다. 오른쪽 위 **게시** 버튼을 눌러야 합니다.

![게시 창. 기본값 '링크가 있는 모든 사용자에게 공개' 그대로 게시합니다](/images/2026-11-27/form-publish-dialog.jpg)

응답자가 "링크가 있는 모든 사용자에게 공개"로 되어 있는지 보고 **게시**를 누릅니다. 게시해도 다른 사람에게 알림이 가지는 않습니다. 게시가 끝나면 버튼 글자가 **"게시됨"**으로 바뀝니다.

주소는 오른쪽 위 **링크 아이콘(🔗)**을 눌러 복사합니다.

![응답자 링크 복사 창](/images/2026-11-27/form-link-copy.jpg)

- **브라우저 주소창의 주소는 쓰지 마세요.** 끝이 `/edit`인 주소는 편집 화면이라 손님이 열 수 없습니다. 손님용 주소는 `…/viewform`으로 끝납니다.
- "URL 단축"은 안 해도 됩니다. 버튼 뒤에 숨는 주소라 길어도 상관없습니다.

## 5. 주소를 클로드에게 건네고 다시 올리기

복사한 주소를 클로드 대화에 그대로 붙여 보냈습니다. 클로드가 폼 주소를 직접 열어 **로그인 없이 열리는지, 질문 5개가 필수인지** 확인하고 나서 파일을 고쳤습니다.

- 문의 버튼 6곳을 구글 폼으로 연결하고, 버튼 이름 "카카오톡 문의"를 "문의하기"로 바꿨습니다.
- 지도 버튼과 "지도 영역" 상자를 지웠습니다.
- 본문에 남아 있던 **"카카오톡이나 전화로"** 같은 문구까지 "문의하기"로 맞췄습니다. 버튼만 바꿨다면 놓쳤을 곳입니다.
- 인스타그램은 계정이 생기면 쓸 수 있게 화면에서만 숨겨 뒀습니다.

받은 `index.html`은 2편과 같은 방법으로 GitHub에 올렸습니다(저장소 첫 화면 `+` → Upload files → 끌어다 놓기 → Commit changes). 52초 뒤 홈페이지에 반영됐습니다.

### 함정 4 - 다운로드 이름이 또 `index (1).html`

2편에서 받은 `index.html`이 다운로드 폴더에 남아 있어서, 이번에도 새 파일이 `index (1).html`로 저장됐습니다. 올리기 전에 예전 파일을 지우고 이름을 `index.html`로 바꿨습니다.

**올리고 나면 다운로드 폴더의 `index.html`을 지워 두세요.** 다음에 받을 때 헷갈리지 않습니다.

## 6. 손님처럼 직접 눌러 봅니다

![오시는 길에는 운영 시간과 문의하기 버튼만 남았습니다](/images/2026-11-27/site-visit-contact.jpg)

마지막으로 홈페이지에서 **문의하기** 버튼을 직접 눌러 봤습니다. 새 탭에 폼이 로그인 없이 열렸습니다.

![손님이 보는 문의 폼](/images/2026-11-27/form-respondent-view.jpg)

폼 위쪽에 메일 주소와 "비공개"가 보여서 잠깐 놀랐습니다. 이건 **지금 폼을 보고 있는 사람 자신의 구글 계정**입니다. "비공개"는 그 메일이 폼 주인에게 넘어가지 않는다는 뜻입니다. 손님 화면에는 손님 계정이 보이거나 아무것도 보이지 않고, **폼을 만든 사람의 메일은 보이지 않습니다.**

새 문의가 오면 바로 알 수 있게 메일 알림도 켜 둡니다. 폼 편집 화면의 **응답** 탭 → 오른쪽 ⋮ → **"새로운 응답에 대한 이메일 알림 받기"**를 누르면 앞에 체크 표시가 붙습니다.

![응답 탭의 ⋮ 메뉴에서 이메일 알림을 켭니다](/images/2026-11-27/form-email-alert.jpg)

## 7. 문의가 오면 이렇게 보입니다

시험 삼아 손님인 척 문의를 하나 남겨 봤습니다. "12월 24일 아이 2명 예약 가능할까요?"라고 쓰고 제출하자 "응답이 기록되었습니다"가 떴고, **1분 안에** 알림 메일이 왔습니다.

![구글 폼 알림 메일. 문의 내용은 들어 있지 않습니다](/images/2026-11-27/gmail-alert.jpg)

알림 메일에는 **문의 내용이 없습니다.** "1개의 새로운 답변"과 [응답 보기] 버튼뿐입니다. 이 메일에 답장을 누르면 손님이 아니라 구글의 발신 전용 주소로 갑니다.

[응답 보기]를 누르면 폼의 응답 화면이 열리고, 거기서 손님 이름·연락처·문의 내용을 봅니다.

![응답 탭. 질문별로 모아 보거나 '개별 보기'로 한 건씩 봅니다](/images/2026-11-27/form-responses.jpg)

- **요약**: 질문별로 모아 봅니다. 문의 종류는 원그래프로 나옵니다.
- **개별 보기**: 문의를 한 건씩 넘겨 봅니다.
- **Sheets에 연결**: 문의가 쌓이면 구글 시트 표로 정리됩니다.

손님에게는 응답에 적힌 연락처로 직접 연락하면 됩니다.

## 공개 전 체크리스트

- [ ] 폼 질문은 5개 안쪽, 모두 필수(빨간 `*`)인지
- [ ] 파일 업로드 질문은 뺐는지 (넣으면 손님이 로그인해야 함)
- [ ] 개인정보 수집·이용 동의를 넣었는지
- [ ] **게시**를 눌렀는지 (버튼이 "게시됨")
- [ ] 주소를 🔗 버튼에서 복사했는지 (`/viewform`으로 끝나는 주소)
- [ ] 올린 파일 이름이 정확히 `index.html`인지
- [ ] 홈페이지의 문의하기 버튼을 직접 눌러 봤는지
- [ ] 새 응답 이메일 알림을 켰는지, 시험 문의로 알림이 오는지
