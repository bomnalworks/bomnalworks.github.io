# 홈페이지 월세 탈출 6편 - 내 도메인 연결하기, 설정 5분에 HTTPS까지 1시간

[5편](/blog/2026-12-04-soap-workshop-search)까지 만든 홈페이지 주소는 `bomnal-lab.github.io`입니다. 무료이고 잘 열리지만, 명함에 넣기엔 조금 깁니다. 이번 편에서는 **내 도메인**으로 홈페이지가 열리게 했습니다.

이 단계는 **선택**입니다. 도메인 값이 1년에 1~2만 원쯤 들고, 안 해도 홈페이지는 그대로 잘 돌아갑니다. 도메인을 사는 과정은 [사업자 홈페이지 만들기 1일차](/blog/2026-11-16-domain-mail-github)에 따로 적었습니다. 저는 그때 Cloudflare에서 산 `bomnalworks.com`의 하위 주소 `lab.bomnalworks.com`을 썼습니다.

실습 사이트는 확인이 끝난 뒤 원래 주소로 되돌려 놨습니다. 그래서 지금 [bomnal-lab.github.io](https://bomnal-lab.github.io/)는 예전처럼 열립니다.

## 결론부터

| 항목 | 결과 |
|---|---|
| 할 일 | GitHub에 주소 적기 1번 + DNS에 기록 1개 추가 |
| 설정 시간 | 약 5분 |
| HTTPS까지 | 1시간 6분 (그중 1시간은 다시 확인 버튼을 안 눌러서 멈춰 있던 시간) |
| 비용 | 도메인 값만 (Cloudflare `.com` 기준 1년 11.17달러) |
| 예전 주소 | 저절로 새 주소로 넘어감 |

- **도메인을 쓸 생각이면 5편(검색 등록)보다 먼저 하세요.** 주소가 바뀌면 검색엔진 네 곳에 다시 등록해야 합니다.
- **GitHub 먼저, DNS는 그다음**입니다.
- DNS 기록을 넣고 10~15분 뒤 **Check again을 눌러 초록 글씨를 확인하세요.** 이걸 안 해서 1시간을 그냥 기다렸습니다.

## 1. 클로드에게 물었습니다

> 내 도메인이 있어. Cloudflare에서 산 bomnalworks.com이야. 이 홈페이지를 lab.bomnalworks.com 주소로 열리게 하고 싶어. 내가 따라 할 수 있게 하나씩 알려줘.

클로드는 "GitHub 설정 한 번, Cloudflare 설정 한 번이면 된다"며 다섯 단계로 정리해 줬습니다.

1. GitHub에 새 주소 적기
2. Cloudflare에 DNS 기록 넣기
3. 연결 확인하고 HTTPS 켜기
4. 새 주소에 맞춘 파일 3개 올리기
5. 검색엔진 등록 다시 하기

![클로드가 정리한 2~5단계. 회색 구름, 화면 배치가 바뀌는 문제, 갤러리 설정까지 짚었습니다](/images/2026-12-08/chat-domain-steps.jpg)

이번 안내는 실제 화면과 거의 다 맞았습니다. 하나만 빠졌는데, 그건 4번에서 다룹니다.

## 2. GitHub에 새 주소부터 적습니다

순서가 중요합니다. 클로드는 **GitHub를 먼저** 하라고 했습니다. DNS를 먼저 연결해 두면 그 사이에 다른 사람이 그 주소를 자기 GitHub 사이트에 가져다 쓸 수 있기 때문이라고 합니다.

1. 저장소 → **Settings** → 왼쪽 **Pages**
2. **Custom domain** 칸에 새 주소(`lab.bomnalworks.com`)를 넣고 **Save**

![Custom domain 칸에 새 주소 입력](/images/2026-12-08/pages-custom-domain.jpg)

저장하면 화면 위 주소가 새 주소로 바뀌고, 저장소에 `CNAME`이라는 파일이 **저절로** 생깁니다. 안에는 새 주소 한 줄이 들어 있습니다. 직접 만들 필요도, 지울 필요도 없습니다.

이때 빨간 글씨로 "DNS check unsuccessful"이 떠도 정상입니다. 아직 DNS를 안 넣었으니까요.

## 3. Cloudflare에 기록을 하나 넣습니다

1. Cloudflare에서 내 도메인 → 왼쪽 **DNS → Records** → **Add record**
2. 아래처럼 넣습니다.

| 칸 | 값 |
|---|---|
| Type | CNAME |
| Name | `lab` (하위 주소 앞부분만) |
| Target | `bomnal-lab.github.io` (앞에 `https://`, 끝에 `/` 없이) |
| Proxy status | 스위치를 꺼서 **회색 구름 "DNS only"** |

![Proxy 스위치를 꺼서 회색 구름 DNS only로 바꾼 상태](/images/2026-12-08/cf-add-record.jpg)

### 함정 1 - 주황색 구름이면 HTTPS가 안 됩니다

Proxy 스위치는 처음에 켜져 있습니다(주황색 구름). 이대로 저장하면 GitHub가 HTTPS 인증서를 받지 못합니다. **꼭 꺼서 회색으로** 바꾸세요.

그리고 스위치를 끄는 순간 위 안내 문장이 한 줄 짧아지면서 **Save 버튼이 위로 올라갑니다.** 원래 자리를 누르면 빗나갑니다. 클로드도 "입력하다 화면 배치가 바뀌어 클릭이 빗나가기 쉬우니 저장 전에 다시 확인하라"고 짚었습니다. 저장 전에 화면을 한 번 더 보세요.

## 4. Check again을 눌러야 시작됩니다

DNS를 넣고 GitHub 화면으로 돌아가 **Check again**을 눌렀습니다. 그러자 "인증서를 요청하는 중, 최대 1시간 걸릴 수 있다"는 안내가 떴습니다. 기다리면 되겠다 싶었습니다.

### 함정 2 - 1시간을 기다려도 그대로입니다

1시간 뒤에 다시 보니 화면이 그대로였습니다.

![1시간 뒤에도 빨간 'DNS check unsuccessful'과 '1 of 3'이 그대로입니다](/images/2026-12-08/pages-stuck.jpg)

빨간 "DNS check unsuccessful"과 "TLS certificate is being provisioned… 1 of 3"이 함께 떠 있습니다. 인증서는 진행 중인 것처럼 보이지만 사실은 멈춰 있던 겁니다. 다른 곳에서 확인해 보니 DNS는 이미 제대로 연결돼 있었습니다.

**Check again을 한 번 더** 누르자 바로 초록색으로 바뀌었습니다.

![다시 누르자 초록 'DNS check successful'](/images/2026-12-08/pages-dns-successful.jpg)

그리고 **1분 만에** 인증서가 나왔습니다.

원인은 이렇습니다. 처음 Check again을 누른 건 DNS 기록을 넣은 지 1분 만이었습니다. 아직 DNS가 GitHub 쪽까지 퍼지기 전이라 확인에 실패했고, **GitHub는 실패한 확인을 저절로 다시 하지 않았습니다.** 화면의 "최대 1시간"은 확인이 성공한 뒤의 이야기였습니다.

클로드 안내에도 "안 뜨면 10~30분 더 기다려 보라"는 말은 있었지만, 다시 눌러야 한다는 말은 없었습니다.

**DNS를 넣고 10~15분 뒤 Check again을 누르고, 초록 "DNS check successful"을 눈으로 확인하세요.** 빨간색이면 몇 분 뒤 또 누릅니다. 초록이 떠야 인증서 발급이 시작됩니다.

## 5. Enforce HTTPS를 켭니다

인증서가 나오면 아래쪽 **Enforce HTTPS** 칸을 체크할 수 있게 됩니다.

![Enforce HTTPS 체크](/images/2026-12-08/pages-enforce-https.jpg)

이걸 켜야 `http://`로 들어와도 `https://`로 넘어갑니다. 안 켜면 주소창에 "안전하지 않음"이 뜨는 주소로도 열립니다.

켠 뒤에 확인해 보니 이렇게 열렸습니다.

- `https://lab.bomnalworks.com` → 정상으로 열림
- 예전 주소 `bomnal-lab.github.io` → 저절로 새 주소로 넘어감

예전 주소가 알아서 넘어가니 명함이나 SNS에 적어 둔 링크는 천천히 바꿔도 됩니다.

## 6. 새 주소에 맞춘 파일 3개 올리기

클로드는 새 주소에 맞게 고친 파일 3개(`index.html`, `sitemap.xml`, `robots.txt`)를 미리 만들어 줬습니다. 주소가 바뀌면서 파일 안에 적힌 옛 주소를 새 주소로 바꾼 것입니다.

- `index.html`: "이 사이트의 대표 주소는 새 주소"라는 표시, 카톡에 링크를 붙였을 때 보이는 미리보기 이미지 주소
- `sitemap.xml`, `robots.txt`: 사이트맵 주소

저는 확인이 끝나면 되돌릴 거라 이 파일들은 올리지 않았습니다. 독자분은 **새 주소가 열린 뒤 세 파일을 같은 이름으로 다시 올리면** 됩니다. 다운로드한 이름에 `(1)`이 붙었으면 고쳐서 올리세요.

### 함정 3 - "공방의 하루" 사진이 사라질 수 있습니다

이 홈페이지의 "공방의 하루" 갤러리는 `images/gallery` 폴더에 사진을 넣기만 하면 저절로 보이게 만들었습니다([1편](/blog/2026-11-21-soap-workshop-homepage)). 그런데 이 기능은 주소가 `○○.github.io`일 때만 저장소 폴더를 읽어 옵니다.

내 도메인으로 바뀌면 폴더를 못 읽고, 대신 `1.jpg`, `2.jpg`… **번호 이름의 사진만** 찾습니다. 제 사진은 마침 번호 이름이라 그대로 보였습니다. 사진 이름을 `여름클래스.jpg`처럼 지은 분은 도메인을 붙이는 순간 갤러리가 비어 보일 수 있습니다.

클로드가 준 새 `index.html`에는 저장소 이름을 직접 적어 넣어서 새 주소에서도 폴더를 읽게 했다고 합니다. **도메인을 붙였다면 새 `index.html`까지 꼭 올리세요.** 올린 뒤 갤러리 사진이 다 보이는지 확인하고, 그래도 비어 있으면 사진 이름을 `1.jpg`, `2.jpg`…로 바꾸면 됩니다.

## 7. 검색엔진 등록은 새 주소로 다시

검색엔진은 주소가 바뀌면 다른 사이트로 봅니다. 클로드가 정리한 대로입니다.

- **구글**: 새 주소로 다시 등록(URL 접두어). 인증 파일은 이미 올라가 있어서 바로 확인됩니다. 사이트맵도 다시 제출
- **Bing**: 구글에 새 주소를 등록한 뒤 다시 가져오기
- **다음**: 새 주소로 PIN을 다시 받고, 새 인증 줄을 `robots.txt`에 넣기
- **네이버**: 새 주소로 다시 등록, 새 인증 파일 올리기

5편의 40분을 한 번 더 해야 합니다. 그래서 **도메인을 쓸 거라면 검색 등록 전에** 하는 편이 일이 적습니다.

## 되돌리는 법

마음이 바뀌어 github.io 주소로 돌아가고 싶으면 두 군데만 고치면 됩니다. 이번 실습에서 실제로 되돌려 봤습니다.

1. GitHub **Settings → Pages → Custom domain** 옆 **Remove**. 확인 창 없이 바로 지워지고, 저장소의 `CNAME` 파일도 저절로 사라집니다.
2. Cloudflare **DNS → Records**에서 그 기록의 Edit → **Delete**. Cloudflare가 "정말 지울까요" 하고 한 번 묻습니다. **다른 기록(메일 등)을 지우지 않게** 이름과 대상을 보고 누르세요.

![Remove를 누르면 바로 원래 주소로 돌아옵니다. DNS 기록도 지우라고 안내합니다](/images/2026-12-08/pages-domain-removed.jpg)

되돌린 뒤 `bomnal-lab.github.io`가 다시 정상으로 열렸고, 5편에서 올린 검색엔진 인증 파일도 그대로였습니다.

## 체크리스트

- [ ] 도메인 연결을 검색 등록보다 먼저 했는지
- [ ] GitHub Custom domain을 먼저 저장했는지
- [ ] DNS 기록: CNAME, 이름은 앞부분만, 대상은 `아이디.github.io`
- [ ] Proxy가 회색 구름(DNS only)인지, 저장 버튼을 다시 보고 눌렀는지
- [ ] 10~15분 뒤 Check again → 초록 "DNS check successful"을 확인했는지
- [ ] 인증서가 나온 뒤 Enforce HTTPS를 켰는지
- [ ] 새 주소용 파일 3개를 올리고 갤러리 사진이 다 보이는지
- [ ] 검색엔진을 새 주소로 다시 등록했는지

## 정리

| 항목 | 결과 |
|---|---|
| 비용 | 도메인 값만 (1년 1~2만 원) |
| 설정 | GitHub 한 번, DNS 기록 하나 |
| 걸린 시간 | 설정 5분, HTTPS까지 1시간 6분 |
| 가장 큰 함정 | Check again 한 번만 누르고 기다린 것 |

이것으로 홈페이지 만들기 본편은 끝입니다. 0원으로 만들고, 고치고, 문의와 예약을 받고, 검색에 알리고, 원하면 내 도메인까지 붙였습니다.
