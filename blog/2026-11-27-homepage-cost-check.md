# 홈페이지 빌더 1년이면 19만 원 - 0원 홈페이지로 바꾸기 전에 확인할 4가지

공방이나 작은 가게를 하면 "내 이름이 걸린 홈페이지" 하나쯤은 있으면 좋습니다. 그런데 막상 만들려고 하면 길이 두 개밖에 안 보입니다. 업체에 맡기거나, 홈페이지 빌더에 매달 사용료를 내거나.

이 글은 세 번째 길, **AI(클로드)와 대화해서 만들고 GitHub에 무료로 올리는 방법**으로 바꾸기 전에 확인할 것을 정리했습니다. 맞지 않는 가게도 있으니 먼저 따져 보세요.

## 1. 지금 1년에 얼마를 내고 있나요

홈페이지 빌더의 가장 싼 유료 요금제입니다. 두 곳 모두 **내 도메인(`내가게.com`)은 이 요금제부터** 쓸 수 있습니다.

| 빌더 | 가장 싼 유료 요금제 | 1년이면 |
|---|---|---|
| 아임웹 | Starter 월 20,000원 (1년 결제 시 월 16,000원) | 약 19만 원 |
| Wix | 라이트 월 14달러 (1년 결제 기준, 세금 별도) | 168달러 (약 24만 원) |

*2026년 11월 각 회사 요금 페이지 기준. 할인 행사, 세금, 환율에 따라 달라집니다.*

빌더는 편집 화면에서 직접 고칠 수 있어 편하지만, **사용료를 내는 동안만** 홈페이지가 열립니다. 3년이면 약 57만~72만 원입니다.

클로드 + GitHub로 옮기면 제작비와 호스팅비가 0원입니다. 내 도메인을 쓰고 싶을 때만 도메인 값이 듭니다. 이 블로그 연재에서 쓴 `.com` 도메인은 1년 11.17달러였습니다. 클로드는 유료 구독으로 따라 했으니, 이미 AI를 구독 중인 분께 맞는 방법입니다.

## 2. 0원 홈페이지로 안 되는 것 4가지

무료에는 이유가 있습니다. **아래 중 하나라도 꼭 필요하면 이 방법은 맞지 않습니다.**

1. **결제, 회원가입, 로그인, 게시판**: 보여 주기만 하는 "소개 홈페이지"입니다. 문의와 예약은 구글 폼처럼 이미 있는 서비스에 연결해서 받습니다([문의 버튼 달기](/blog/2026-11-27-soap-workshop-contact)).
2. **쇼핑몰**: GitHub Pages 규칙은 상거래가 주목적인 사이트를 허용하지 않습니다. 가게를 소개하는 홈페이지는 괜찮고, 물건은 스마트스토어 같은 곳으로 링크를 겁니다.
3. **비밀로 두기**: 무료로 열려면 저장소를 공개해야 합니다. 집 주소, 개인 전화번호, 손님 사진은 올리지 않습니다.
4. **아주 큰 사이트**: 전체 용량 1GB, 한 달 방문 데이터 100GB가 기준입니다(2026년 11월 GitHub 안내). 사진 몇십 장짜리 소개 홈페이지에는 넉넉합니다.

## 3. 시간은 얼마나 드나요

연재에서 가상의 "봄날비누공방" 홈페이지를 처음부터 만들며 잰 시간입니다.

| 단계 | 걸린 시간 | 연재 글 |
|---|---|---|
| 클로드와 시안 만들고 공개 | 약 1시간 (첫 시안은 5분) | [1편](/blog/2026-11-21-soap-workshop-homepage) |
| 공개한 홈페이지 고치기 | 3~14분 | [2편](/blog/2026-11-24-soap-workshop-edit) |
| 문의 버튼(구글 폼) | 약 20분 | [3편](/blog/2026-11-27-soap-workshop-contact) |
| 예약 신청 받기 | 약 15분 | 4편 (12/1) |
| 검색엔진 4곳 등록 | 약 40분 | 5편 (12/4) |
| (선택) 내 도메인 | 설정 5분 + 인증서 기다리기 | 6편 (12/8) |

1편부터 검색 등록까지 **3시간이 안 걸렸습니다.** 가장 오래 걸린 건 "더 마음에 들게" 다듬는 시간이었습니다.

## 4. 처음 보낼 한 문장

프롬프트를 배울 필요는 없습니다. 내 가게 이야기를 편하게 하고 끝에 이 한 문장만 붙이세요.

> 좋은 예제 프롬프트를 제안해줘. 2개만

프롬프트를 직접 쓰는 대신 **만들어 달라고** 하는 겁니다. 그리고 시안을 받기 전에 이 문장도 꼭 먼저 보내세요.

> 나는 터미널이나 자동 배포는 못 써. GitHub 웹 화면에서 파일만 올리면 되게 만들어줘.

이 말을 안 하면 개발자용 설정이 섞여 나와서 갑자기 어려워집니다.
