# 홈페이지 월세 탈출 5편 - 검색에 나오게 하기, 구글·네이버·다음·Bing 등록

[4편](/blog/2026-12-01-soap-workshop-booking)까지 홈페이지에 문의와 예약 버튼을 달았습니다. 그런데 검색엔진은 이 홈페이지가 있는지 아직 모릅니다. 이번 편에서는 **구글, 네이버, 다음, Bing**에 등록했습니다.

같은 일을 개발 도구(Claude Code)로 한 기록은 [사업자 홈페이지 만들기 3편](/blog/2026-11-21-search-engine-registration)에 있습니다. 이번에는 독자와 같은 조건으로 **클로드 채팅과 GitHub 웹 화면만** 썼습니다.

결과물: [bomnal-lab.github.io](https://bomnal-lab.github.io/)

## 결론부터

| 검색엔진 | 소유 확인 방법 | 사이트맵 | 걸린 시간 |
|---|---|---|---|
| 구글 | HTML 파일 올리기 | 제출 | 약 5분 |
| Bing | 구글에서 가져오기 | 저절로 따라옴 | 약 5분 |
| 다음 | PIN 정하기 + robots.txt에 한 줄 | 수집 요청 | 약 10분 |
| 네이버 | HTML 파일 올리기 + 보안문자 | 제출 | 약 10분 |

- 전체 **약 40분**, 비용 0원
- 사이트에 올린 파일은 네 개뿐입니다: 구글 인증 파일, 네이버 인증 파일, `sitemap.xml`, `robots.txt`
- **index.html은 한 줄도 고치지 않았습니다.**

## 1. 내 홈페이지 주소부터 알려 줍니다

평소처럼 클로드에게 물었습니다.

> 이제 검색에 나오게 하고 싶어. 구글, 네이버, 다음, 빙에 등록하는 방법을 알려줘. 내가 따라 할 수 있게 하나씩.

클로드는 순서를 **구글 → Bing → 네이버 → 다음**으로 정리해 줬습니다. Bing은 구글 등록을 그대로 가져올 수 있어서 구글을 먼저 하는 게 좋다는 이유였습니다.

![클로드가 내 주소를 모른 채 '저장소이름이 붙은 주소'라고 가정했습니다](/images/2026-12-04/chat-root-assumption.jpg)

### 함정 1 - 클로드가 내 주소를 짐작합니다

첫 단계에 이런 경고가 있었습니다. "지금처럼 `아이디.github.io/저장소이름/` 형태면 다음(Daum) 등록이 막혀요. 저장소 이름을 `아이디.github.io`로 바꾸세요."

제 홈페이지는 이미 `bomnal-lab.github.io`로 열리는데, 클로드가 주소를 모르니 짐작한 것입니다. 이렇게 다시 말했습니다.

> 내 주소는 https://bomnal-lab.github.io/ 야. 이미 루트 주소야. sitemap.xml이랑 robots.txt 만들어줘.

그러자 클로드가 주소를 직접 열어 확인한 뒤 파일을 만들어 줬습니다. **검색 등록을 물을 때는 내 홈페이지 주소를 먼저 알려 주세요.**

그렇다고 이 경고가 쓸모없지는 않습니다. 저장소 이름이 `아이디.github.io`가 아니면 주소 뒤에 `/저장소이름/`이 붙고, 다음 등록에 필요한 `robots.txt`가 제자리에 놓이지 않습니다. [1편](/blog/2026-11-21-soap-workshop-homepage)에서 저장소 이름을 `아이디.github.io`로 정확히 쓰라고 한 이유입니다.

## 2. sitemap.xml과 robots.txt부터 올립니다

검색엔진에 알려 줄 파일 두 개를 먼저 받았습니다.

- **sitemap.xml**: "이 사이트에는 이런 페이지들이 있어요"라는 목록입니다. 한 장짜리 홈페이지라 주소 한 줄이 전부입니다.
- **robots.txt**: 검색 로봇이 가장 먼저 읽는 안내문입니다. "사이트 전체를 수집해도 된다"는 내용과 사이트맵 위치가 들어 있습니다.

![클로드가 만든 robots.txt. 맨 아래에 다음 인증 코드를 넣을 자리를 비워 뒀습니다](/images/2026-12-04/chat-robots-sitemap.jpg)

두 파일을 GitHub 저장소 첫 화면에서 `+` → Upload files로 올렸습니다. `images` 폴더 안이 아니라 `index.html`과 같은 자리에 있어야 합니다. 올리고 1~2분 뒤 `https://내주소/robots.txt`가 열리면 됩니다.

## 3. 구글 - HTML 파일 방식이 가장 쉽습니다

1. [Google Search Console](https://search.google.com/search-console)에서 **웹사이트 추가**를 누릅니다.
2. 오른쪽 **URL 접두어**에 내 주소를 넣습니다. 왼쪽 "도메인"은 내 도메인을 산 경우에 쓰는 방식이라 `github.io` 주소에는 쓸 수 없습니다.

![URL 접두어에 주소 입력](/images/2026-12-04/gsc-url-prefix.jpg)

3. 소유권 확인 방법이 나옵니다. 맨 위 **권장 확인 방법인 HTML 파일**을 펼쳐 파일을 다운로드합니다.

![구글이 권장하는 방법은 HTML 파일입니다](/images/2026-12-04/gsc-html-file.jpg)

클로드는 "HTML 태그" 방식을 안내했습니다. 이 방식은 `index.html` 안에 한 줄을 넣어야 해서 파일을 고쳐 다시 올려야 합니다. 반면 HTML 파일 방식은 **받은 파일을 그대로 올리기만 하면** 됩니다. 저는 앞의 두 파일과 함께 한 번에 올렸습니다.

4. 반영된 뒤 **확인**을 누르면 "소유권이 확인됨"이 뜹니다.

![소유권이 확인됨](/images/2026-12-04/gsc-verified.jpg)

5. 왼쪽 **Sitemaps**에 `sitemap.xml`을 넣고 제출합니다.

### 함정 2 - 사이트맵이 "가져올 수 없음"으로 나옵니다

![제출 직후 상태가 빨간 글씨로 '가져올 수 없음'](/images/2026-12-04/gsc-sitemap-cannot-fetch.jpg)

제출하자마자 상태에 빨간 글씨로 <strong>"가져올 수 없음"</strong>이 떴습니다. 주소를 직접 열어 보면 파일은 정상입니다. 새로 등록한 사이트는 처음에 이렇게 뜨는 경우가 많습니다. 하루이틀 기다렸다가 다시 보세요. 이 사이트의 상태가 바뀌면 이 글에 덧붙이겠습니다.

## 4. Bing - 구글에서 가져오면 끝입니다

1. [Bing Webmaster Tools](https://www.bing.com/webmasters)에 로그인합니다. Microsoft, Google, Facebook 계정 중 하나로 로그인할 수 있습니다.
2. 사이트 추가 방법 중 왼쪽 **Import your sites from GSC**(구글 서치콘솔에서 가져오기)를 누릅니다.

![왼쪽이 구글에서 가져오기. 사이트 인증이 필요 없습니다](/images/2026-12-04/bing-import.jpg)

3. 영어로 된 안내가 나옵니다. 요약하면 "구글에서 확인된 사이트 목록과 사이트맵만 가져오고, 방문 통계는 가져오지 않는다. 구글 서치콘솔 **보기 전용 권한**으로 인증 상태를 주기적으로 확인한다"는 내용입니다.
4. 구글 계정을 고르고 권한을 허용합니다. 이 화면은 내 계정 권한을 넘기는 동의라서 직접 읽고 누르세요.
5. 가져올 사이트 목록에서 **이번에 등록할 사이트만** 체크합니다. 구글에 다른 사이트를 등록해 둔 분은 목록에 다 나옵니다.

![사이트맵까지 저절로 들어왔습니다](/images/2026-12-04/bing-sitemap.jpg)

가져오기가 끝나니 사이트맵도 저절로 들어와 "Processing(처리 중)"으로 떴습니다. Bing에 등록하면 야후 검색에도 함께 반영됩니다.

## 5. 다음 - 계정 대신 PIN입니다

다음 웹마스터도구는 로그인 방식이 다릅니다. 계정 대신 **사이트마다 PIN을 정해서** 그걸로 들어갑니다.

1. [다음 웹마스터도구](https://webmaster.daum.net/)에서 **PIN코드 발급받기**를 누릅니다.
2. 사이트 주소를 넣고 PIN(영문+숫자 8~12자)을 정합니다. **PIN은 꼭 적어 두세요.** 다음에 들어갈 때 다시 씁니다.
3. 발급이 끝나면 `#DaumWebMasterTool:`로 시작하는 한 줄이 나옵니다.

![이 한 줄을 robots.txt 맨 아래에 넣습니다](/images/2026-12-04/daum-pin-done.jpg)

4. 이 줄을 클로드에게 보내면서 "robots.txt에 넣어줘"라고 했습니다. 클로드는 "보내 주신 코드와 한 글자도 다르지 않은지 대조했다"며 새 `robots.txt`를 줬고, 그걸 같은 이름으로 다시 올렸습니다.
5. 반영된 뒤 **인증 시작하기**에 사이트 주소와 PIN을 넣으면 관리 화면이 열립니다. 사이트 이름은 페이지 제목에서 가져와 "봄날비누공방"으로 자동 표시됐습니다.
6. 위쪽 **수집요청** 메뉴에서 홈페이지 주소와 사이트맵 주소를 넣습니다.

![사이트맵은 수집요청 화면의 맨 아래 칸입니다](/images/2026-12-04/daum-sitemap.jpg)

수집요청 화면에는 입력 칸이 세 개 있습니다. 맨 위 "문서등록"에 홈페이지 주소를, **맨 아래 "사이트맵" 칸**에 `sitemap.xml` 주소를 넣습니다. 가운데 칸(RSS 피드용)은 비워 둡니다.

### 함정 3 - 다운로드 이름이 또 바뀝니다

두 번째로 받은 robots.txt는 다운로드 폴더에 `robots (1).txt`로 저장됐습니다. 2편부터 계속 나온 함정입니다. **올리기 전에 이름을 `robots.txt`로 정확히 맞추세요.**

## 6. 네이버 - 보안문자는 직접

네이버도 구글처럼 HTML 파일 방식을 권장합니다.

1. [네이버 서치어드바이저](https://searchadvisor.naver.com/)에 로그인하고 오른쪽 위 **웹마스터 도구**를 누릅니다.
2. 사이트 등록 칸에 주소를 넣습니다.
3. 소유확인 화면에서 **HTML 파일 업로드**를 고르고 파일을 받습니다.

![네이버도 HTML 파일 방식을 권장합니다](/images/2026-12-04/naver-ownership.jpg)

4. 받은 파일을 GitHub에 올립니다. 구글 파일은 사이트가 달라도 이름이 같았는데, **네이버 파일은 사이트마다 새로** 줍니다.
5. 반영된 뒤 **소유확인**을 누르면 보안문자가 나옵니다. 그림 속 글자를 입력합니다.

![소유 확인 완료. 검색 노출은 보장하지 않는다고 안내합니다](/images/2026-12-04/naver-verified.jpg)

6. 사이트 목록에서 내 사이트를 눌러 들어간 뒤, 왼쪽 **요청 → 사이트맵 제출**에 `sitemap.xml` 주소를 넣고 확인합니다.
7. 같은 메뉴의 **웹 페이지 수집**에 홈페이지 주소를 넣고 확인합니다.

![요청 → 사이트맵 제출](/images/2026-12-04/naver-sitemap.jpg)

## 등록하면 바로 나올까요?

아닙니다. 보통 며칠에서 2주쯤 걸리고, 네이버 안내처럼 **검색 노출이 보장되지도 않습니다.** 등록은 "이 사이트가 있다"고 알리는 일이고, 실제로 보여 줄지는 검색엔진이 정합니다.

그리고 사이트에 올린 **인증 파일과 robots.txt의 인증 줄은 지우면 안 됩니다.** 검색엔진이 주기적으로 다시 확인하기 때문에, 지우면 인증이 풀립니다.

## 체크리스트

- [ ] 클로드에게 내 홈페이지 주소를 먼저 알려 줬는지
- [ ] `sitemap.xml`과 `robots.txt`를 `index.html`과 같은 자리에 올렸는지
- [ ] 구글: URL 접두어 + HTML 파일 + 사이트맵 제출
- [ ] Bing: 구글에서 가져오기, 내 사이트만 체크
- [ ] 다음: PIN 적어 두기, 인증 줄은 robots.txt 맨 아래, 사이트맵은 맨 아래 칸
- [ ] 네이버: HTML 파일 + 보안문자, 사이트맵 제출과 웹 페이지 수집
- [ ] 올린 파일 이름에 `(1)` 같은 번호가 붙지 않았는지
- [ ] 인증 파일을 지우지 않았는지

## 정리

| 항목 | 결과 |
|---|---|
| 비용 | 0원 |
| 등록한 곳 | 구글, Bing, 다음, 네이버 |
| 사이트에 올린 파일 | 구글·네이버 인증 파일, `sitemap.xml`, `robots.txt` |
| 걸린 시간 | 약 40분 |

이것으로 소개 홈페이지에 필요한 기본은 다 갖췄습니다. 만들고, 고치고, 문의와 예약을 받고, 검색에 알렸습니다. 다음 편에서는 `bomnal-lab.github.io` 대신 **내 도메인**을 연결하는 방법을 다룹니다. 이 단계는 선택이고, 도메인 비용이 1년에 1~2만 원쯤 듭니다.
