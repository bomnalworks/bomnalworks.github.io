# 사업자 홈페이지 만들기 3편 — 구글·네이버·다음·Bing 검색 등록 한 번에 끝내기

1편에서 홈페이지를 열고, 2편에서 데모 서버를 올렸습니다. 그런데 사이트는 열려 있어도 검색엔진은 이 사이트가 있는지 모릅니다. 이번에는 이 홈페이지(bomnalworks.com)와 운세 오락실(play.bomnalworks.com) 두 곳을 **구글, 네이버, 다음, Bing**에 등록했습니다.

이번에도 클로드와 같이 했습니다. 클로드가 화면을 열고 인증 파일을 만들어 배포했고, 저는 로그인과 PIN 정하기, 권한 동의처럼 제 계정에 관한 것만 눌렀습니다.

## 오늘 한 일

| 검색엔진 | 소유 확인 방법 | 사이트맵 | 걸린 시간 |
|---|---|---|---|
| 구글 서치콘솔 | HTML 파일 / 구글 애널리틱스 | 제출, 상태 "성공" | 약 15분 |
| 네이버 서치어드바이저 | HTML 파일 | 제출 | 약 15분 |
| 다음 웹마스터도구 | robots.txt에 인증 줄 추가 | 수집 요청 | 약 20분 |
| Bing 웹마스터 도구 | 구글 서치콘솔에서 가져오기 | 자동으로 따라옴 | 약 10분 |

네 곳 모두 비용은 0원입니다. 대부분의 시간은 배포가 끝나기를 기다리는 데 썼습니다.

## 소유 확인이란

검색엔진은 아무나 남의 사이트를 등록하지 못하게, "이 사이트가 정말 당신 것인지" 먼저 확인합니다. 방법은 대개 셋 중 하나입니다.

- 검색엔진이 준 **파일을 사이트에 올리기**
- 검색엔진이 준 **한 줄을 사이트 안에 넣기**
- 이미 연결된 **다른 서비스(구글 애널리틱스 등)로 증명하기**

정적 사이트는 파일을 `public` 폴더에 넣고 푸시하면 1~2분 뒤 공개됩니다. 그래서 파일 방식이 가장 편했습니다.

## 1. 구글 — 한 곳은 클릭 한 번으로 끝났습니다

구글 서치콘솔에서 속성을 추가할 때 "도메인"과 "URL 접두어" 중 하나를 고릅니다. 도메인 방식은 DNS 설정이 필요해서, 사이트마다 URL 접두어로 등록했습니다.

- **운세 오락실**: 주소를 넣자마자 "소유권이 자동으로 확인됨"이 떴습니다. 페이지에 이미 구글 애널리틱스를 달아 두었고, 같은 구글 계정이라 그걸로 확인된 것입니다.
- **홈페이지**: 애널리틱스가 없어서 HTML 파일을 받아 올렸습니다. 배포가 끝난 뒤 "확인"을 누르니 통과했습니다.

확인되면 "Sitemaps" 메뉴에 `sitemap.xml`을 넣어 제출합니다. 두 곳 모두 상태 "성공", 페이지 4개가 읽혔습니다.

### 막힌 곳 1 — robots.txt가 없었습니다

홈페이지를 VitePress로 만들었는데, 사이트맵은 자동으로 생기지만 `robots.txt`는 없었습니다. 검색 로봇이 가장 먼저 읽는 파일이라 하나 만들었습니다.

```
User-agent: *
Allow: /

Sitemap: https://bomnalworks.com/sitemap.xml
```

이 파일은 아래 다음 웹마스터도구에서도 쓰입니다.

## 2. 네이버 — 화면은 직접 눌러야 했습니다

네이버 서치어드바이저는 클로드가 쓰는 브라우저 확장에서 열리지 않았습니다. 그래서 등록 화면은 제가 직접 눌렀고, 클로드는 인증 파일만 만들어 배포했습니다.

1. 웹마스터 도구에 사이트 주소 입력
2. 소유 확인 방법으로 **HTML 파일** 선택 → 파일 이름(`naver…html`)을 클로드에게 전달
3. 클로드가 파일을 만들어 배포 → 주소로 열리는지 확인
4. "소유확인" 버튼 → 사이트맵 제출

사이트가 두 개라 이 과정을 두 번 했습니다. 인증 파일은 사이트마다 이름이 다릅니다.

## 3. 다음 — 계정이 아니라 PIN입니다

다음 웹마스터도구는 로그인 방식이 다릅니다. 계정 대신 **사이트마다 PIN 코드를 정해서** 그걸로 들어갑니다.

1. "PIN코드 발급받기"에서 사이트 주소를 넣고 PIN을 정합니다
2. 화면에 `#DaumWebMasterTool:…`로 시작하는 한 줄이 나옵니다
3. 이 줄을 `robots.txt` 맨 아래에 붙여 배포합니다
4. 사이트 주소와 PIN으로 "인증하기"

### 막힌 곳 2 — 인증 줄에 사이트 이름이 없습니다

발급 화면의 인증 줄에는 어느 사이트용인지 적혀 있지 않습니다. 두 사이트를 연달아 발급받으면 어느 줄이 어느 사이트 것인지 헷갈립니다. **하나 발급 → 바로 붙여 배포 → 다음 사이트** 순서로 하는 게 안전합니다.

### 막힌 곳 3 — 브라우저가 PIN 칸을 멋대로 채웁니다

PIN 입력칸에 브라우저가 저장해 둔 다른 비밀번호를 자동으로 채워 넣었습니다. 지우고 새로 정해야 합니다. 정한 PIN은 꼭 적어 두세요. 다음에 들어갈 때 다시 씁니다.

들어간 뒤에는 "수집요청" 메뉴의 **사이트맵** 칸에 `sitemap.xml` 주소를 넣어 요청합니다.

## 4. Bing — 구글에서 가져오면 끝입니다

Bing은 가장 쉬웠습니다. 로그인한 뒤 "Google Search Console에서 가져오기"를 누르면, 구글에서 이미 확인된 사이트와 사이트맵을 그대로 가져옵니다. 소유 확인을 다시 할 필요가 없습니다.

### 막힌 곳 4 — 권한 동의는 내 손으로

가져오기를 누르면 구글 계정 선택과 권한 동의 화면이 나옵니다. 서치콘솔 읽기 권한과 이메일을 Bing에 넘기는 동의라서, 이 화면은 클로드에게 맡기지 않고 직접 읽고 눌렀습니다.

### 막힌 곳 5 — 다른 사이트까지 전부 체크돼 있습니다

가져올 사이트 목록에 서치콘솔에 등록된 **모든 사이트**가 체크된 채로 나왔습니다. 저는 예전 블로그들까지 다섯 개가 떠 있었습니다. 이번에 등록할 두 곳만 남기고 체크를 풀었습니다.

## 정리

| 항목 | 결과 |
|---|---|
| 비용 | 0원 |
| 등록한 곳 | 구글, 네이버, 다음, Bing × 사이트 2개 |
| 사이트에 추가한 파일 | 구글·네이버 인증 파일, `robots.txt`(다음 인증 줄 포함) |
| 주의 | 인증 파일과 robots.txt의 인증 줄을 지우면 인증이 풀립니다 |

등록했다고 바로 검색에 나오지는 않습니다. 보통 며칠에서 2주쯤 걸립니다. 실제로 검색에 잡히기 시작하면 그때 수치를 다시 적겠습니다.
