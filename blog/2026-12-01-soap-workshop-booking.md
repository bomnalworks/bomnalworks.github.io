# 홈페이지 월세 탈출 4편 - 예약과 결제는 직접 만들지 말고 링크로

[3편](/blog/2026-11-27-soap-workshop-contact)에서 홈페이지에 문의 버튼을 달았습니다. 이번에는 한 걸음 더 나가 **예약과 결제**를 받아 보려고 했습니다.

먼저 원칙부터 정했습니다. **홈페이지에 예약·결제 기능을 직접 만들지 않습니다.** 결제를 직접 받으려면 서버, 결제 대행사 계약, 개인정보 보호까지 책임질 게 많아집니다. 이 연재에서 쓰는 무료 호스팅(GitHub Pages)은 쇼핑몰처럼 거래가 중심인 사이트에 쓰지 말라는 약관도 있습니다. 그래서 **이미 있는 예약·결제 서비스에 링크로 연결**하고, 거래 처리는 그 서비스에 맡깁니다.

결과물: [bomnal-lab.github.io](https://bomnal-lab.github.io/) (상단과 첫 화면의 "예약하기" 버튼)

## 결론부터

| 단계 | 걸린 시간 |
|---|---|
| 클로드에게 예약·결제 방법 묻기 | 약 4분 |
| 방법 고르고 수정안 받기 | 약 3분 |
| 구글 폼에 날짜 질문 추가 | 약 3분 |
| 고친 파일 올리고 확인 | 약 3분 |
| **합계** | **약 15분**, 비용 0원 |

- **완전히 0원인 방법은 "예약 신청을 받고 계좌이체로 결제"하는 것 하나뿐**입니다. 카드나 간편결제는 어느 서비스든 결제 수수료가 붙습니다.
- 네이버 예약이나 원데이클래스 플랫폼은 <strong>실제 사업자와 매장(또는 강사)</strong>이 있어야 씁니다.
- 처음이라면 3편에서 만든 구글 폼에 **"희망 날짜·시간" 질문 하나**를 더하는 것으로 충분합니다.

## 1. "무료"의 범위부터 정리합니다

이번에도 1편을 만든 대화에서 이어서 물었습니다.

> 이제 예약이랑 결제도 받고 싶어. 홈페이지에 직접 만들지 말고, 이미 있는 서비스에 링크로 연결하는 방법 2~3가지 제안해줘. 언제나 그렇듯이 돈 안 드는 걸로.

![클로드는 '완전히 무료인 방법은 하나뿐'이라는 말로 답을 시작했습니다. 수수료 숫자는 직접 확인하세요](/images/2026-12-01/chat-booking-options.jpg)

클로드의 첫 문장이 이번 편의 요점이었습니다.

> 돈이 전혀 안 드는 방법은 "예약 신청을 받고 계좌이체로 결제하는 방식" 하나뿐이에요.

"무료"라는 말에는 두 가지가 섞여 있습니다.

| | 뜻 | 예 |
|---|---|---|
| 가입비·월 이용료 0원 | 서비스를 쓰는 데 고정비가 없다 | 네이버 예약, 원데이클래스 플랫폼 등록 |
| 결제 수수료 0원 | 돈이 오갈 때 떼는 몫이 없다 | 계좌이체로 직접 받기 |

카드나 간편결제로 받는 순간 수수료가 생깁니다. 클로드는 "가입비와 월 이용료가 없는" 기준으로 세 가지를 골랐습니다.

| 방법 | 좋은 점 | 걸리는 점 |
|---|---|---|
| 네이버 예약 (스마트플레이스) | 네이버 지도·검색에서 바로 예약 | 등록할 때 사업자 정보 확인, 지도에 실제 매장이 올라감. 선결제는 결제 수수료 |
| 원데이클래스 플랫폼 (솜씨당 등) | 예약과 결제를 플랫폼이 모두 처리 | 팔릴 때마다 플랫폼 수수료, 실제 강사와 장소 필요 |
| 구글 폼 예약 신청 + 계좌이체 | 완전 무료, 사업자 등록·심사 없음 | 입금 확인과 일정 관리를 손으로, 시간이 겹치지 않게 직접 챙겨야 함 |

네이버 예약의 결제 수수료는 클로드가 숫자까지 말했지만, 공식 자료에서 같은 숫자를 찾지 못했습니다. 수수료율은 바뀌고, 영세 가맹점 지원 행사도 수시로 열립니다. **실제로 쓰기 전에 네이버페이센터 안내에서 직접 확인하세요.**

### 가상 공방으로 돈을 받으면 안 됩니다

이 대목은 제가 말하기 전에 클로드가 먼저 짚었습니다.

> 운영하지 않는 공방 이름으로 실제 돈을 받으면 손님이 피해를 볼 수 있어요.

이 연재의 예시는 가상 공방이라 실제 예약과 입금은 받지 않습니다. 실습에서는 3번 방법을 "흐름만 보여 주는 버전"으로 만들었습니다. 실제 가게라면 그대로 쓰고, 계좌만 안내하면 됩니다.

## 2. 시간이 겹치는 건 어떻게 막을까

3번 방법의 약점은 같은 시간에 두 사람이 신청할 수 있다는 점입니다. 그래서 이렇게 물었습니다.

> 3번이 좋은데, 같은 시간에 예약이 겹치지 않게 자동으로 막아 주는 무료 방법은 없어?

![자동으로 막는 방법 두 가지](/images/2026-12-01/chat-no-overlap.jpg)

클로드가 찾은 방법은 두 가지였습니다.

- **구글 폼 + 무료 부가기능**: 시간대마다 정원을 정해 두면 꽉 찬 시간은 선택지에서 사라집니다. 다만 남이 만든 부가기능에 **내 구글 폼 접근 권한**을 줘야 합니다. 거의 동시에 신청하면 정원을 넘을 수 있다는 점도 부가기능 설명에 적혀 있습니다.
- **구글 캘린더 예약 일정**: 개인 구글 계정이면 예약 페이지 1개를 무료로 만들고 예약을 무제한으로 받을 수 있습니다. 내 캘린더에 일정이 있는 시간은 자동으로 막힙니다. 다만 1:1 약속용이라 한 시간에 한 건씩 잡히고, **예약 페이지에 내 구글 계정의 이름과 사진이 공개됩니다.**

둘 다 쓸 만하지만, 처음 하는 분에게는 권한을 주거나 개인 정보를 드러내는 부담이 있습니다. 이번에는 **자동 차단 없이 폼에 날짜 질문만 추가**하기로 했습니다. 대신 홈페이지 문구로 정직하게 알립니다.

> 신청하신 시간은 확인 후 확정 안내를 드려요.

## 3. 클로드에게 폼 수정안과 새 파일 받기

> 부가기능 없이 할게. 지금 문의 폼에 희망 날짜·시간 질문만 추가하는 걸로 하자. 폼에 넣을 질문이랑 홈페이지 예약하기 버튼까지 정리해줘.

![구글 폼에서 바꿀 것과 홈페이지에서 바뀐 것](/images/2026-12-01/chat-booking-plan.jpg)

이번에는 클로드가 묻지 않고 바로 고친 `index.html`을 줬습니다. 구글 폼은 직접 고쳐야 해서 바꿀 내용만 정리해 줬습니다.

**구글 폼에서 바꿀 것**
1. "문의 종류"와 "문의 내용" 사이에 새 질문 **"희망 날짜·시간"**
2. 유형은 **날짜**, 질문 카드 ⋮ → **시간 포함**
3. **필수는 끕니다.** 주문제작이나 기타 문의는 날짜가 필요 없기 때문입니다.
4. 설명: "클래스 예약이라면 원하는 날짜와 시간을 골라주세요. 확인 후 확정 안내를 드려요."
5. 폼 설명 끝에 "실습용이라 실제 예약과 입금은 받지 않습니다." (실습용일 때만)

**홈페이지에서 바뀐 것**
- 상단 메뉴 오른쪽에 검은 **예약하기** 버튼 (휴대폰 화면에서는 아래쪽 버튼과 겹치지 않게 숨김)
- 첫 화면 큰 버튼과 어린이 클래스 버튼이 **예약하기**로
- 진행 과정과 오시는 길 문구를 "확인 후 확정 안내"로

## 4. 구글 폼에 날짜 질문 넣기

1. 폼 편집 화면에서 **"문의 종류" 질문을 먼저 누릅니다.** 오른쪽 막대의 ⊕를 누르면 새 질문이 **선택한 질문 바로 아래**에 생깁니다.
2. 제목에 "희망 날짜·시간"을 씁니다. 이번에는 유형이 저절로 바뀌지 않아서, 유형 목록 아래쪽의 **날짜**를 직접 골랐습니다.
3. 질문 카드 오른쪽 아래 ⋮를 누르면 **설명 / 시간 포함 / 연도 포함**이 나옵니다. 처음에는 연도 포함만 켜져 있습니다. **시간 포함**을 누르면 날짜 칸 아래에 시간 칸이 생깁니다.
4. ⋮를 한 번 더 눌러 **설명**을 켜고 안내 문장을 넣습니다. 필수 스위치는 꺼 둡니다.

![다 켠 뒤의 ⋮ 메뉴. 설명·시간 포함·연도 포함 앞에 모두 체크 표시가 붙었습니다](/images/2026-12-01/form-date-menu.jpg)

이미 게시한 폼은 **고치면 바로 손님 화면에 반영**됩니다. 다시 게시할 필요가 없었습니다.

## 5. 올리고 확인하기

받은 `index.html`은 2·3편과 같은 방법으로 올렸습니다(저장소 첫 화면 `+` → Upload files → Commit changes). 이번에도 다운로드 폴더에 예전 파일이 있어서 `index (1).html`로 받아졌고, 이름을 `index.html`로 바꿔 올렸습니다. 1분이 안 돼서 반영됐습니다.

![상단과 첫 화면에 예약하기 버튼이 생겼습니다](/images/2026-12-01/site-booking-button.jpg)

**예약하기**를 누르면 3편에서 만든 폼이 열리고, 날짜와 시간을 고르는 칸이 보입니다.

![손님 화면의 날짜·시간 칸. 시간은 AM(오전) / PM(오후)으로 고릅니다](/images/2026-12-01/form-date-respondent.jpg)

한국어 화면인데도 시간은 **AM / PM**으로 나옵니다. 오전은 AM, 오후는 PM입니다.

## 6. 실제로 돈을 받기 시작하면

실습에서는 돈을 받지 않았지만, 실제 가게라면 아래를 먼저 확인하세요.

- **통신판매업 신고**: 인터넷으로 상품이나 서비스(클래스처럼 시설을 이용하는 권리도 포함)를 팔고 주문을 받으면 통신판매업 신고 대상이 될 수 있습니다. 공정거래위원회 고시에 따라 **직전 연도 통신판매 거래가 50회 미만이거나 간이과세자이면 신고하지 않아도 됩니다.** 내 경우가 어디에 해당하는지는 관할 시·군·구청에 확인하세요.
- **사업자 정보 표시**: 신고한 통신판매업자는 홈페이지 같은 판매 화면에 상호, 대표자 이름, 주소, 전화번호, 메일, 신고번호를 적어야 합니다. 2편에서 클로드가 "온라인으로 판매하게 되면 사업자 정보를 표시해야 할 수도 있다"고 했던 부분입니다.
- **결제 서비스 가입**: 카드 결제를 받으려면 네이버 예약, 원데이클래스 플랫폼, 결제 대행사 같은 서비스에 사업자로 가입합니다. 홈페이지에는 그 예약·결제 페이지의 **링크만** 겁니다.

## 체크리스트

- [ ] "무료"가 가입비 0원인지, 결제 수수료까지 0원인지 구분했는지
- [ ] 사업자가 필요한 서비스라면 실제 사업자로 가입했는지
- [ ] 날짜 질문: 유형 **날짜** + ⋮ → **시간 포함**, 필수는 끔
- [ ] 자동으로 겹침을 막지 않는다면 "확인 후 확정 안내" 문구를 넣었는지
- [ ] 홈페이지의 예약하기 버튼을 직접 눌러 봤는지
- [ ] 돈을 받기 전에 통신판매업 신고 대상인지 확인했는지

## 정리

| 항목 | 결과 |
|---|---|
| 추가 비용 | 0원 |
| 예약 받는 곳 | 구글 폼 (3편 문의 폼에 날짜·시간 질문 추가) |
| 걸린 시간 | 약 15분 |
| 홈페이지에서 바뀐 것 | 예약하기 버튼, 확정 안내 문구 |

이제 홈페이지로 문의도 예약 신청도 받을 수 있습니다. 다음 편에서는 이 홈페이지가 **검색에 나오도록** 구글·네이버·다음·Bing에 등록합니다.
